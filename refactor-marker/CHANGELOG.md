# 変更履歴

## 0.2.0 — 2026-10-21

- 1 つのグループに複数ファイルの複数範囲を登録できるようにし、追加順を保持。**Add to Existing Group** を追加し、同一グループ内を含む重複・行単位の重なりを拒否。
- **Create Group** で同じワークスペースフォルダーの同じ完全パスを指定した場合は、既存の色・ID を維持して範囲を追加。名前は大文字・小文字を区別し、前後の空白は入力時だけ除去。
- 既存データの同名グループは、作成日時がすべて有効なら最古、欠落を含む場合は保存順で最初のグループの ID・色を保持して整理。欠落日時を既存情報などから補完し、範囲の完全一致だけを重複除去。それ以外の重なりや保存失敗ではデータを捨てずに停止。
- 名前変更で既存グループと同じ完全パスを指定した場合は拒否し、暗黙の統合を防止。
- サイドバー上部に **Add to Existing Group** ボタンを追加。通常のサイドバー・選択一覧から内部 UUID の表示を削除し、グループ名・ファイル・行番号・範囲数で識別。
- 範囲を個別に追従・無効化し、無関係な範囲やグループを保持。Windows のパス表記の違いと、フォルダーごとの独立した保存に対応。
- メタデータと生成ファイルを `.vscode/cache/refactor-marker/` に集約。スキーマバージョンを明示し、新メタデータがない場合は v0.1.0 の単一範囲データを移行。旧ファイルを保持し、失敗時は通知して上書きを防止。
- 7 色の背景色を一元管理し、不透明度を約 30% に変更。
- Orange のアイコンを VS Code 標準の色登録機構による拡張専用テーマ色へ変更し、通常・ハイコントラストの明暗テーマ向けに橙色を指定。他 6 色とエディターの背景色は維持。
- 文字・数字・半角スペース・`-`・`_`・`/` の名前検証を追加し、パスから階層と仮想の親を構成。名前変更・削除は選択した実グループだけに適用。
- **Export Group as Function** を追加。最上位の階層全体を PascalCase の入れ子関数として出力し、範囲の追加順、範囲ごとの相対パスのコメント、ファイル名の競合検査、標準の上書き確認に対応。
- 出力はリファクタリング用の下書きに限定。import・依存関係・引数・戻り値・非同期処理の分析や自動生成、元のソースの置き換えは行わず、正しい TypeScript やコンパイル可能性は保証しない。
- 社内配布用に `refactor-marker-0.2.0.vsix` を生成。バージョン番号は据え置き。
- 社内利用向けにテストコードとテストランナーを削除し、`check` をコンパイルと lint に整理。
- README を日本語の `README.md` に一本化し、言語切り替えリンクを削除。変更履歴と確認記録も日本語に統一。

### レビューでの修正

- キャッシュ・メタデータ・ソースのシンボリックリンクやジャンクションを拒否し、書き込み先の転送、ワークスペース外への参照、生成ファイルや重複検査の回避を防止。
- 同じ物理ルートの二重登録を拒否し、入れ子のワークスペースルートでも復元・移行・変更・編集追従時の重なりを検査。
- 範囲のどちらか一方の境界をまたぐ空でない置換でも、影響した範囲だけを無効化。
- エクスポート前に追従処理の待ち行列を待ち、一時ファイルの保存後、出力先の置き換え直前にもソースの版とグループ情報を再確認。
- コピーする範囲の先頭行だけに追加インデントを付け、複数行文字列や行継続の内容を保持。
- グループの選択一覧へソースの位置を表示し、同じ表示名のワークスペースはフォルダーパスで識別。
- サイドバーの無効な範囲を別の位置へ丸めず拒否し、エディターを開いた後も最新の追従位置を解決。

## 0.1.0 — 2026-10-20

個人での試用・社内検証向けの初期版。

- 名前と 7 色の背景色で、行全体のマーカーグループを作成。
- `.vscode/refactor-marker.json` へ保存し、ワークスペースを開くと復元。
- VS Code 標準のコマンドで名前変更・色変更・削除・全削除を提供。
- サイドバーでファイル別にグループを表示し、範囲へ移動。
- グループの重なりを拒否し、ドキュメントの変更に合わせて位置を保守的に追従。
- 当時はロジック確認用のテスト、分離した拡張機能開発ホスト用ランナー、ローカル VSIX の作成手順を同梱。

### 0.1.0 に含まれる修正

- Windows のファイルパスの大文字・小文字を、装飾・追従・重複検査・サイドバーで一貫して照合。
- 周囲のコードを含む置換では曖昧なマーカーを警告付きで無効化。
- 一部フォルダーの保存が失敗しても、ワークスペース構成の更新と正常なフォルダーの保存を継続し、書き込みエラーを通知。
- 当時の単体確認と拡張機能開発ホストで、これらの修正を確認。

### 当時の文書

- インストール・使用方法・開発・プライバシー・初期版の制限を、英語と日本語の README に記載。
- 当時の VSIX では言語切り替え用の相対リンクを保持。
